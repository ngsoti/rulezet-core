How does Velociraptor push work?
[[ editMode ? 'Edit Velociraptor server' : 'New Velociraptor server' ]]
The `api_connection_string` field from your Velociraptor API client config YAML — a bare host:port, e.g. 127.0.0.1:8001. Not the GUI URL (that's a different port, typically 8889) and no https:// prefix.
The `ca_certificate` field — public, not sensitive.
The `client_cert` field — encrypted at rest. Never shown back once saved; leave blank to keep the existing one.
The `client_private_key` field — encrypted at rest. This grants full API access to your Velociraptor deployment; only add servers you trust this instance's admins with. Never shown back once saved; leave blank to keep the existing one.
